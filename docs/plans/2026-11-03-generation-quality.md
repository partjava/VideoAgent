# 六项生成质量优化实施计划

用户已确认前一轮审查中的六项优化，且暂不进行付费生成验证。

实现顺序：
1. 编写离线回归测试，覆盖时间轴、动作覆盖、连续性输入、时长限制、ComfyUI 映射和媒体质检。
2. 引入统一分镜时间轴、结构化动作节拍与全片角色约束；为连续动作建立实际尾帧续接。显式切镜保持独立构图。
3. 修复分镜级配音定位、短视频补帧与字幕共用计划时间轴；素材缺失直接失败。
4. 分镜时长严格匹配目标，服务不得静默截断；Wan 透传时长比例；ComfyUI 上传首帧并转换合法帧数。
5. 质检检查解码、时长、比例、音轨、字幕及素材完整性；输出限制说明，不能宣称完成视觉语义质检。
6. 使用合成媒体和模拟服务回归，不请求任何付费 API。补充使用与验证文档。

保留已有前端与模型选择；不创建新的付费审核模型。尾帧续接仅用于明确标记的连续动作镜头，角色一致性仍需后续实际模型验证。

## 使用与验证

- 建议从新任务使用这套分镜约束。历史成片不会被改写；旧分镜总长不符合当前目标时长时，续跑会提示失败。
- 新任务的分镜总长必须等于用户选择的目标时长，单镜为 4–12 秒。视频服务实际返回过短时，最多补 0.5 秒尾帧，超过范围应修复该分镜。
- 连续动作只生成需要的首帧，继承前一镜头实际展示的尾帧。换机位或跨场景重新构图并复用全片角色与世界设定。仅当缓存的连续镜头确实使用当前尾帧时才复用。
- 自定义 ComfyUI 视频工作流须映射 `positive_prompt`、`image_path`、`width`、`height`、`length`、`fps`，将首帧连接到视频节点，并返回 MP4。默认工作流已更新。
- Wan 2.7 的比例由上传首帧决定，适配器会先整理首帧比例，并发送时长。参见 [Wan 图生视频指南](https://help.aliyun.com/zh/model-studio/wan-image-to-video-guide) 与 [ComfyUI Wan 首帧节点](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/Wan22ImageToVideoLatent/en.md)。
- 配音和图片就绪后才提交视频。配音允许最高 1.2 倍速度，超出时提前报告分镜编号。字幕按实际可用配音时长显示。最终质检报告位于任务输出目录的 `quality_report.json`，并标出内容仍需人工确认。

在安装后端依赖后，从 `backend` 运行 `python -m unittest discover -s tests -v`。离线测试只使用模拟接口与本地合成媒体，覆盖尾帧传递、首帧参数映射、分镜时间轴、短配音后的留白、字幕和坏文件拦截。未运行真实生成服务，不消耗生成额度。
